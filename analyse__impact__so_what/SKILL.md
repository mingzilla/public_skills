# Principle: So what — impact analysis

## The five questions

1. **So what? Why does it matter?** What changes because this exists?
2. **What value does it bring?** Specifically: efficiency, accuracy, quality, or another lever — name the lever.
3. **If we start again (e.g. restart design), would we do it differently?** Honest answer; if yes, what?
4. **What are the wasted steps?** Which steps in the path didn't contribute to the outcome?
5. **What's the shortest path to the same outcome?** Trim steps until removing one would change the result.

### Waste of effort analysis

For non-trivial solutions, draw a table of every step taken to connect the entry and the outcome:

| Step          | Outcome contribution    |
|---------------|-------------------------|
| `<step name>` | unavoidable / skippable |

- **Outcome contribution** — `unavoidable` means removing the step changes the result; `skippable` means removing it leaves the result intact.

The table makes the wasted-steps and shortest-path questions concrete: skippable rows are candidates to drop.
