## Usage

> - Usage: Use `unit__rule__make_concise` for skills

## Why should I care?

### Before (Without this skill)

```text
It is generally considered good practice that, wherever possible, you
should try to make sure that the output directory is cleaned up before
a new run begins, as leftover files may sometimes cause problems.
```

"generally", "wherever possible", "sometimes" - the reader cannot tell if this is required.

### After (With this skill)

```text
Delete `_output/` before each run.
```
